# App Teste Operacional

Versao navegavel simples da esteira Empresarial e Societaria 360.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Escopo

- Dashboard da esteira.
- Navegacao entre etapas.
- Caso simulado Alfa Prime.
- Mapa de risco.
- Controle de qualidade.
- Plano de acao resumido.

Esta versao nao depende de servidor, build ou instalacao de pacotes.
