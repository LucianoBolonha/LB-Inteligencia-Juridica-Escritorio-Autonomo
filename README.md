# LB Inteligencia Juridica - Escritorio Autonomo

Projeto de estruturacao da LB Inteligencia Juridica como escritorio de advocacia digital, enxuto e orientado por IA, com foco em:

- Planejamento patrimonial e sucessorio
- Planejamento tributario
- Planejamento empresarial e societario

## Objetivo

Construir uma plataforma operacional e comercial para um escritorio autonomo, combinando estrategia juridica, esteira comercial, producao documental, agentes de IA, governanca humana e metricas de performance.

- `docs/00-visao-geral.md` - posicionamento, principios e escopo macro
- `docs/01-blueprint-estrategico.md` - mapa do escritorio autonomo
- `docs/02-produtos-e-ofertas.md` - produtos juridicos, pacotes e recorrencia

- `docs/04-agentes-de-ia.md` - arquitetura de agentes, papeis e supervisao

## Versao teste operacional

A versao teste fica em `app-teste-operacional/index.html`.

Ela pode ser aberta direto no navegador ou servida localmente:

```powershell
Set-Location .\app-teste-operacional
python -m http.server 5178 --bind 127.0.0.1
```

Depois, acesse `http://127.0.0.1:5178/`.
